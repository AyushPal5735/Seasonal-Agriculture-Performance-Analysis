# Seasonal Agriculture Performance Analysis

VOIS AICTE Batch 1 (2026–2027) Major Project

## Files
- `Seasonal_Agriculture_Performance_Analysis.ipynb` — completed Jupyter Notebook
- `seasonal_agriculture_performance_dataset.csv` — original supplied dataset
- `VOIS_Major_Project_Seasonal_Agriculture_Performance_Completed.pptx` — completed PPT using the supplied template
- `Project_Report_Seasonal_Agriculture_Performance.pdf` — supporting project report
- `charts/` — analysis charts
- `code_snippets/` — code images used in the PPT
- `SUBMISSION_CHECKLIST.txt` — final submission checklist

## Dataset
4000 rows × 28 columns.
Missing values before cleaning: 120.
Missing values after median imputation in the analysis copy: 0.

## Main analysis
The project investigates seasonal differences in yield, production, revenue, cost, profit, water usage, water efficiency, environmental conditions and disease/pest risk. It also compares crops, irrigation methods, states and crop-season combinations.
